📋 1. Job Desk Dasar & Estimasi Gaji (Pasar Kerja)

IT Support bertanggung jawab merawat, memperbaiki, dan memastikan seluruh infrastruktur teknologi informasi di perusahaan berjalan lancar.

  • Pemeliharaan Perangkat: Merawat dan mendiagnosis PC, Laptop, Printer, Proyektor, dan CCTV.
  • Pengelolaan Software: Instalasi OS (Windows/Linux), pembaruan sistem, dan aplikasi produktivitas kantor.
  • Bantuan Pengguna (Helpdesk): Menjadi garda depan penyelesaian kendala teknis karyawan, baik langsung maupun via remote.

B. Alur Kerja Sistem Tiket (Ticketing System)

Sistem antrean digital (Contoh: Jira, Zendesk) untuk melacak keluhan karyawan:

  1. Open: User membuat tiket keluhan di aplikasi (misal: Wi-Fi terputus).
  2. In Progress: IT Support menerima tiket dan mengubah status agar user tahu masalah sedang ditangani.
  3. Resolved & Closed: Masalah diselesaikan di lapangan, IT mencatat dokumentasi solusi di sistem, lalu menutup tiket.

🌐 3. Logika Praktis & Pemecahan Masalah Jaringan (CMD)

Metode pelacakan mandiri menggunakan Command Prompt (CMD) yang telah dipraktikkan:

A. Perintah ping - Tes Koneksi Utama

  • ping 8.8.8.8: Menguji jalur ke DNS server global Google. Jika mendapat Reply, berarti laptop terhubung internet luar.
  • Jika muncul Request timed out (RTO) sesekali, jaringan sedang tidak stabil (interferensi Wi-Fi atau beban bandwidth tinggi).
  • Jika ping google.com berhasil menerjemahkan nama domain ke IP, fungsi DNS Server berjalan normal.

B. Perintah ipconfig & tracert

  • ipconfig: Melihat IP lokal laptop dan Default Gateway (Alamat IP Router pengubung).
  • tracert google.com: Melacak rute perjalanan data melewati gerbang-gerbang server (Hops). Jika RTO di awal (Hop 1), masalah ada di router lokal. Jika RTO/putus mulai di Hop 2 atau 3, masalah ada di sisi provider internet luar (ISP).
💡 Kunci Studi Kasus Interview Jaringan:
Jika ping google.com hasilnya RTO total, tetapi ping 192.168.1.1 (Router) hasilnya lancar, artinya Komputer user & Jaringan lokal kantor AMAN. Titik kerusakan mutlak ada pada jalur internet dari Provider (ISP) yang terputus.

🛡️ 4. SOP Keamanan Siber: Penanganan Ransomware

Pertanyaan ini menguji kesiapan Anda melindungi aset penting perusahaan saat terjadi serangan darurat.

Pertanyaan Interview: "Apa yang Anda lakukan jika komputer user mendadak terinfeksi Ransomware (.locked)?"

Langkah Penyelamatan Terstruktur (Jawaban Terbaik):

  • Langkah 1 Isolasi Jaringan Segera: Cabut kabel LAN atau matikan koneksi Wi-Fi pada laptop korban secepat mungkin. Alasan: Mencegah Ransomware menyebar ke komputer lain atau server utama kantor melalui jaringan lokal.
  • Langkah 2 Laporkan ke Atasan/Tim Security: Berikan eskalasi laporan guna mengantisipasi serangan siber berskala besar.
  • Langkah 3 Clean Install & Restore: Format total drive sistem (Clean Install) untuk memusnahkan virus, kemudian pulihkan data user menggunakan file cadangan (Backup) resmi terakhir perusahaan.

⚙️ 5. Troubleshooting Hardware & Install Windows Aman

A. PC Menyala tapi Layar Hitam (No Display)

CPU hidup, kipas berputar, tetapi monitor menampilkan pesan No Signal. Langkah penyelesaiannya:

  1. Matikan arus listrik komputer demi keamanan.
  2. Buka casing CPU, cabut komponen RAM dari slotnya.
  3. Trik Utama: Bersihkan pin kuningan RAM menggunakan penghapus pensil secara perlahan untuk menghilangkan debu atau korosi ringan.
  4. Pasang kembali dengan kokoh, lalu uji nyalakan. Jika gagal, coba pindahkan ke slot RAM yang berbeda.

B. Standar Prosedur (SOP) Instalasi Ulang OS Windows di Kantor

  • Wajib Backup Data: Amankan folder data krusial user (Desktop, Documents, Downloads, Pictures) serta bookmark browser ke eksternal storage sebelum eksekusi.
  • Gunakan Installer Resmi: Buat bootable USB menggunakan Media Creation Tool dari web resmi Microsoft demi menghindari malware.
  • Fokus Format: Saat proses instalasi, hanya hapus dan format Drive C (System). Jangan mengganggu Drive D atau E yang menyimpan data historis pekerjaan karyawan.
