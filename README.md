# 🛠️ IT Support Knowledge Base & Troubleshooting Portfolio

Selamat datang di repositori basis pengetahuan (*knowledge base*) IT Support saya! Repositori ini berisi rangkuman tugas, dokumentasi sistem penanganan keluhan (*ticketing*), panduan pelacakan jaringan secara berkala, hingga standar operasional prosedur (SOP) keamanan siber yang saya kuasai dan siap saya terapkan di dunia kerja.

Projek ini dibuat interaktif dalam satu halaman web responsif yang dilengkapi dengan fitur *Dark Mode*.

---

## 🚀 Fitur Utama Halaman Web

- **Panduan Job Desk & Estimasi Gaji:** Peta karier IT Support di Indonesia.
- **Manajemen Administrasi IT:** Simulasi pengelolaan aset inventaris kantor dan alur kerja sistem tiket (*ticketing system*).
- **Logika Praktis Jaringan:** Metode investigasi jaringan menggunakan perintah CMD (`ping`, `ipconfig`, `tracert`).
- **SOP Keamanan Siber:** Protokol penanganan darurat terhadap serangan siber Ransomware.
- **Troubleshooting Hardware:** Solusi taktis mengatasi PC menyala tanpa tampilan (*No Display*) dan prosedur instalasi ulang Windows.
- **Interaktivitas:** Fitur tombol alih tema (*Dark Mode / Light Mode*) yang dinamis.

---

## 🗂️ Struktur Folder Repositori

```text
├── index.html   # Struktur utama konten dan halaman web

└── README.md    # Dokumentasi utama projek (Halaman ini)
```

## 🛠️ Teknologi & Peralatan yang Digunakan

- **HTML5:** Menyusun konten dokumen secara terstruktur.
- **CSS3:** Memberikan gaya tampilan modern menggunakan variabel CSS.
- **JavaScript (ES6):** Mengatur fungsionalitas manipulasi DOM dan penyimpanan lokal (*Local Storage*).
- **Command Prompt (CMD):** Digunakan untuk melakukan investigasi dan praktik jaringan secara langsung di lapangan.

---

## 💻 Cara Menjalankan Projek Secara Lokal

1. Klik tombol **Code** di bagian atas repositori ini, lalu pilih **Download ZIP** (atau gunakan perintah `git clone`).
2. Ekstrak file ZIP tersebut di komputer Anda.
3. Buka folder projek, lalu klik dua kali pada file `index.html`.
4. Halaman web otomatis akan terbuka di peramban (*browser*) Anda tanpa perlu koneksi internet.

## 🎙️ Kesiapan Menghadapi Interview Kerja

Melalui projek mandiri ini, saya telah melatih logika pemecahan masalah (*troubleshooting isolation*) untuk beberapa skenario penting:
1. **Isolasi Jaringan:** Memutus penyebaran Ransomware dengan cepat melalui penonaktifan kartu jaringan fisik atau nirkabel.
2. **Pelacakan Titik Rusak:** Menggunakan kombinasi `ping` dan `tracert` untuk membedakan gangguan perangkat internal kantor dengan gangguan massal dari pihak provider (ISP).
3. **Efisiensi Biaya Hardware:** Mengatasi kendala *No Display* akibat tumpukan debu pada pin kuningan RAM menggunakan metode pembersihan statis (penghapus pensil).
